# 我的待办 · 日历

一个可以「安装成应用」的待办清单。输入事项和时间即可添加，勾选后进入已完成，右侧日历标注每天的具体安排。

数据默认只存在你自己浏览器的 localStorage 里——不联网、不上传、不需要账号。
想让手机和电脑看到同一份待办，运行 `启动局域网同步.bat` 就能在同一个 WiFi 下自动同步，数据不出你的局域网。

界面是 **iOS 风格**：系统色板（systemBlue 作主色）、大标题毛玻璃导航栏、
分组圆角卡片列表（分隔线左对齐到文字）、提醒事项那种圆形勾选、日历里今天显示红字、
选中日期是反色实心圆。深浅色跟随系统，右上角可手动切换。

动效是**毛玻璃 + 光感**，四层叠出来的质感：SVG 噪点（`feTurbulence`，同时盖住渐变色带）→ 斜向高光 →
半透明底色 → 1px 受光边（用遮罩把中间掏空只留边）。
背后铺了四团**有机形状**的光斑（不是正圆，四个角半径各不相同，再叠极慢旋转，看上去像在缓缓变形），
它们就是「光透过玻璃」的来源。每张卡片另有一道极慢的高光掠过，各卡片时间错开，不会一起闪。
新增或勾选的条目会**从中心放大淡入**；页面载入时各区块依次上浮。

系统开了「减弱动态效果」时会全部关掉（前庭敏感的人会不适）。

**字体**：统一微软雅黑 Light。
关键写法是基字重设成 `font-weight:300` —— Chromium 走 DirectWrite，会把
`msyh`/`msyhbd`/`msyhl` 三个文件合成一个 **"Microsoft YaHei"** 家族（Light/Regular/Bold），
所以 300 能取到 Light 字面，而标题按钮上的 600/700 拿到的是**真粗体**，
不是那种边缘发虚的合成加粗。
（实测判据：同一串文字 300 宽 216.38、400 宽 223.45、700 更宽——三者不同即证明字面切换生效。）

> 注意 `Microsoft YaHei Light` 在 GDI+ 里是**独立家族**，直接把它写在字体栈最前面也可以出 Light，
> 但那样所有粗体都会退化成合成加粗。用字重方案才对。

## 三种打开方式

| 方式 | 怎么做 | 适合 |
| --- | --- | --- |
| **桌面客户端**（推荐） | 双击桌面上的「我的待办」快捷方式 | 平时使用。真正的桌面程序：独立窗口、没有地址栏、没有浏览器痕迹，双击即开 |
| **浏览器版** | 双击 `启动我的待办.bat` | 想在浏览器里用、或想在手机上访问时 |
| **手机 / 多设备** | 双击 `启动局域网同步.bat` | 同一个 WiFi 下手机也能用，并和电脑自动同步 |
| **直接打开文件** | 双击 `index.html` | 只是快速看一眼。功能相同，但浏览器不允许在 `file://` 下安装成应用 |

> 如果桌面上没有快捷方式（比如换了电脑、或移动过文件夹），
> 双击 `创建桌面快捷方式.ps1`（右键 → 使用 PowerShell 运行）重新生成一个。

## 桌面客户端

`desktop/` 是一个 Electron 应用，**不是浏览器套壳**：本地服务跑在应用自己的主进程里
（`server.js` 被 `require` 进去了），窗口加载的是本机地址。所以：

- 是一个原生窗口，有自己的任务栏图标；没有地址栏，菜单栏里也没有任何浏览器的东西
- **不用另外开服务**——打开客户端就等于服务已经在跑，而且用户看不到任何「服务器窗口」
- 手机同步、离线缓存这些能力全都保留（它们本来就依赖 http 环境）
- 只允许开一个实例，重复双击会把已有窗口拉到前面

菜单里能做的事：

- **文件 → 允许手机访问（局域网同步）**：勾上即开，会弹窗告诉你手机该输哪个地址，再点一次取消。
  等价于命令行版的 `启动局域网同步.bat`，但不用另外开窗口
- **文件 → 打开数据文件夹**：直接定位到数据文件
- **视图**：重新加载、开发者工具、缩放、全屏

**数据放在哪**：直接跑（未打包）时用项目里的 `data/`，和浏览器版共用同一份，两边互通；
打包成 exe 后放在 `%APPDATA%\我的待办\data\`（安装目录可能只读）。

**注意**：桌面快捷方式指向的是 `desktop/node_modules` 里的 Electron。
所以**整个文件夹不能拆散**；想拷到别的电脑，请先打包（见下）。

### 打包成免安装 exe

```
cd desktop
npm install
npm run dist
```

产物在 `desktop/dist/我的待办-1.0.0.exe`：单文件、免安装，拷到别的 Windows 机器上双击就能用。

> 如果 `npm install` 卡在下载 Electron 二进制（国内访问 GitHub 慢），加镜像重试：
> `set ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ && npm install`

手机上用：在同一个 WiFi 下双击 `启动局域网同步.bat`，脚本会直接告诉你手机该输哪个地址。
在手机浏览器里打开它，再用「添加到主屏幕」存一个图标即可。

## 多设备同步

双击 `启动局域网同步.bat`（不是平时那个），脚本会：

1. 让本地服务额外监听局域网（平时只监听 127.0.0.1，手机连不上）；
2. 打印出手机要输入的地址，形如 `http://192.168.1.5:8765/`。

手机连同一个 WiFi，浏览器输入那个地址就能用，**两端改动会自动互相同步**：

- 一端改了、另一端最多 5 秒后自动出现；切回窗口时也会立刻拉一次。
- 加、改、勾选完成、删除，全都会同步过去（包括「清空已完成」）。
- 没网也能用：改动先存在本机，等重新连上（服务在跑）自动补齐。

标题栏右侧有个指示灯：绿点「已同步」、黄点「同步中」、红点「同步失败」、
灰点「仅本机」（表示当前服务没有同步接口，数据只在这台设备上）。

### 它是怎么保证不打架的

每条待办带一个「最后修改时间」，两边合并时**同一个 id 谁的修改时间更新就听谁的**。
删除不是真删，而是留一个「墓碑」标记，这样另一台设备才知道这条是被你删了，
而不是把它当成新条目又同步回来。

代价是：两台设备同时改**同一条**待办时，晚改的那次会覆盖早改的那次（另一边的修改会丢）。
日常用基本碰不到，但心里有数。

### 几个必须知道的限制

- **只在同一个 WiFi 下有效。** 出门用不了，除非做内网穿透（见下）。
- **手机上装不成 App、也用不了离线。** 浏览器规定只有 `https` 和 `localhost` 算「安全上下文」，
  通过局域网 IP 访问时 Service Worker 用不了。同步功能不受影响，但手机只能当普通网页用。
- **局域网内其他设备能读写你的待办**，数据不加密。所以请只在可信的网络（比如家里）开这个模式；
  平时就用 `启动我的待办.bat`（只监听本机）。
- **电脑要开着**，手机才连得上。
- 首次运行 Windows 会弹防火墙询问，必须点「允许访问」。
- 家用路由器通常会给电脑分配变化的 IP。地址变了就重跑一次脚本看新地址；
  想固定的话，在路由器里给这台电脑绑定一个固定内网 IP。

### 想跨网络（出门也能用）怎么办

需要满足两件事：一个稳定的地址，以及 `https`（后者顺带解决手机上装 App 的问题）。
现成的做法有 Tailscale / ZeroTier 组虚拟局域网，或 Cloudflare Tunnel；
也可以把这份静态页面传到 GitHub Pages / Cloudflare Pages，再把 `server.js` 里的
`/api/data` 换成坚果云 WebDAV 或 Supabase 之类的存储。

客户端那套合并逻辑（`mergeTasks` / `updatedAt` / 墓碑）是通用的，
换后端只需要替换 `index.html` 里 `fetchJSON` 那几个请求的地址，其余不用动。

## 手动同步 / 备份

页面底部有「导出备份」和「导入」：

- **导出备份** 下载一个 JSON 文件（不含删除记录），可以用来备份或传给另一台设备；
- **导入** 把文件合并进来，同样按修改时间取较新的那份，
  所以**重复导入同一个文件不会产生重复项**（前提是文件里有 id）。

不想开局域网同步的话，靠这两个按钮 + 网盘/微信传文件也能凑合同步。

## 怎么用

1. **添加**：上面输入事项 → 选时间（默认已填「一小时后」，可直接改）→ 回车或点「添加待办」。
   也可以点「今天 09:00」「明天 09:00」这类快捷按钮，一步设定时间。
2. **完成**：点每条前面的圆圈，它就会划掉并移进下面的「已完成」区；再点一下可以恢复。
3. **收起 / 展开**：「倒计时」和「待办事项」标题右边各有「收起」，点一下折叠成一行，带动画。
   折叠状态记在本机，下次打开保持。
4. **倒计时**：左栏最上面一栏，把**带时间的未完成事项**按紧迫程度排好，每条显示还剩几天 ——
   红 = 已过期（「过期 3 天」）、橙 = 今天、蓝 = 7 天内、灰 = 更远。
   点某条会跳到日历上那天。它和下面的「待办事项」是同一批数据的两个视角，所以两边都会出现。
5. **每周**：右下角按 ISO 周（周一起算）汇总，显示「第 N 周」、日期区间和完成进度 `已完成/总数`，
   本周会标出来。**点某一周会从屏幕中间弹出窗口**，里面按天分组、按时间顺序把这一周的事项列出来，
   每条依次淡入下滑。点右上角 ✕、按 Esc、或点窗口外面都能关掉。
6. **日历**：右侧每月视图，**日期数字的颜色就是那天的状态** ——
   红 = 有已过期还没做的，蓝 = 有待办，绿 = 都做完了，不上色 = 那天没安排。
   一天里混着几种状态时，按最要紧的那档显示（过期 > 待办 > 完成）；
   今天在数字外圈加一道描边，跟状态颜色不冲突。
   **点某一天**，下方会列出当天每条事项的具体时刻，左侧列表也同步筛成那天；再点一次取消筛选。
7. **编辑 / 删除**：鼠标移到条目上，右侧出现 ✎（编辑，会回填到顶部表单）和 ✕（删除）。
8. 点条目正文，会跳到日历里对应的那天。

其他：右上角 ☾/☀ 切换深浅色（默认跟随系统）；「清空已完成」清理已完成条目。

## 数据在哪

两份，各管一摊：

1. **浏览器 localStorage**（键名 `todo_calendar_v1`）——你看到的东西就是它。**不在这份文件夹里**。
2. **`data/todo.json`**——只有开着局域网同步时才有，是服务端那份，给多设备同步用的。

所以要留意：

- 换浏览器、换电脑，localStorage 不会跟着走（但开了局域网同步的话，新设备一连上就能拿到数据）；
- 清除浏览器数据会清掉本机的待办（服务端 `data/todo.json` 还在，下次连上会同步回来）；
- 卸载「安装成应用」的那个 App，可能会连带清掉它的数据；
- 备份用页面底部的「导出备份」。

> **来源不同，数据就是两套。** localStorage 按「协议 + 域名 + 端口」隔离，所以
> `http://127.0.0.1:8765`、`http://192.168.3.100:8765`、`file://` 三者互相看不见对方的本地数据。
> 这正是需要同步功能的原因——开着局域网同步时它们会通过服务端汇合；
> 不开的话，就是三份互不相干的待办。

## 关于那个本地服务

`server.js` 是一个零依赖的 Node 脚本，做两件事：把本目录当静态站点发出去（PWA 的离线缓存和
「安装成应用」都要求 http 环境），以及提供 `/api/data` 存取待办数据给多设备同步用。
不联网、只读这个文件夹。

**默认只监听 `127.0.0.1`**，也就是只有这台电脑能访问。要开多设备同步才需要监听局域网，
用 `启动局域网同步.bat`。

**关掉它**：任务栏里那个最小化的「服务」窗口，关掉即可；或者任务管理器结束 `node.exe`。

**改了文件**：刷新即可看到最新版——页面走「网络优先」，每次打开都会取最新的，顺手更新离线缓存。
改的若是 `icons/`、`manifest.webmanifest` 这类走「缓存优先」的静态资源，
要把 `sw.js` 里的 `VERSION` 加一（`v3` → `v4`）才会生效。

## 文件结构

```
index.html              应用本体（单文件：页面 + 样式 + 逻辑，无任何外部依赖）
manifest.webmanifest    应用信息：名称、图标、启动方式
sw.js                   Service Worker：离线缓存
server.js               本地服务 + 同步接口（零依赖；既能命令行跑，也能被嵌入）
data/todo.json          服务端那份数据，多设备同步时用
desktop/                桌面客户端（Electron）
  main.js               主进程：把服务跑在里面 + 原生窗口 + 菜单
  package.json          依赖与打包配置
  node_modules/         依赖（含 Electron，体积较大，可删；删了要重新 npm install）
icons/                  各尺寸图标（含桌面客户端用的 app.ico）
tools/make-icons.py     重新生成图标：python tools/make-icons.py
launch.ps1              浏览器版一键启动的逻辑（-Lan = 局域网模式）
启动我的待办.bat         浏览器版：只在本机用
启动局域网同步.bat       浏览器版：手机也能连、多设备同步
创建桌面快捷方式.ps1      在桌面生成客户端快捷方式
```

> `启动我的待办.bat` 里刻意只写英文：cmd.exe 按系统 ANSI 编码解析 .bat，
> 文件里放 UTF-8 中文会被拆错、导致脚本执行失败。中文提示都放在 `launch.ps1`（带 BOM）里。

## 想再改点什么

`index.html` 里三块是分开的，都在同一个文件内：

- 顶部 `<style>` —— 就是一套 iOS 设计变量，改这里就能整体换配色：
  - `:root` 里是浅色，`html[data-theme="dark"]` 里是深色；
  - `--blue` 主色、`--red` 过期、`--green` 已完成，对应 iOS 的 systemBlue / systemRed / systemGreen；
  - `--bg` 页面底色、`--card` 卡片色、`--label-*` 三级文字色、`--sep` 分隔线；
  - 想换主题色，连 `icons/` 一起换掉（跑 `python tools/make-icons.py`，改脚本顶部的 `START`/`END` 两个色值）。
- 动效相关的都在 `<style>` 末尾那块「动效」里，几个常用旋钮：
  - 光斑的**颜色和形状**在 `.b1`~`.b4`（`border-radius` 的斜杠语法 = 四个角各自的横/纵半径，
    改了它形状就变；写成 `50%` 就是正圆），**漂移和旋转的快慢**在 `drift1`~`drift4` 的秒数；
  - 光斑**浓度**是 `--blob-op`（深色下默认更淡）；
  - **噪点**是 `--glass-grain`，那个 data-URI 里的 `opacity` 控制强度；
  - 高光掠过的**频率**在 `@keyframes sheen` 的 `13s`，各卡片的错开时间在紧跟其后的几条 `animation-delay`；
  - 淡入动画是 `.pop-in`（`popIn` 关键帧），页面载入的上浮是 `riseIn`；
  - `--glass-tint` / `--glass-sheen` / `--glass-rim` 分别是底色、斜向高光和受光边。

> 两个踩过的坑，改的时候注意：
> 1. 折叠用的是 `grid-template-rows: minmax(0,1fr) → minmax(0,0fr)`。**不能只写 `0fr`** ——
>    `fr` 自带一个 auto 最小值，实测收起后仍会残留 32px 压不下去。
> 2. `touch()` 里更新时间戳用的是 `max(现在, 原值 + 1)` 而不是直接用 `Date.now()`。
>    这样即使设备时钟不准、或数据里混进了异常的未来时间戳，本地这次修改也一定盖得过旧版本，
>    不会出现「勾了又自己弹回去」。
- 中间是页面结构，列表和日历都是「分组标题 + 圆角卡片」两段式；
- 底部 `<script>` —— 逻辑，入口在最后的 `init()`；数据格式是
  `{ id, title, time, done, createdAt, doneAt, updatedAt, deleted }`，
  `time` 是 `"YYYY-MM-DDTHH:mm"` 本地时间字符串，`updatedAt` 是同步用的最后修改时间，
  `deleted: true` 是删除墓碑。

> 同步的合并规则（`mergeTasks`）在 `index.html` 和 `server.js` 里各有一份，
> 改的时候记得两边一起改，否则两端的判定会不一致。

> 图标用 `tools/make-icons.py` 重新生成（需要 Pillow）。脚本按 1024 的设计稿坐标画图，
> 再等比缩放出各尺寸，`maskable` 版本会自动把主体缩进安全区，供安卓自适应裁切。
